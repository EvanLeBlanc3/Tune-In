# Tune In v1.1 — install
All files sit at the top level now (no folders), so any upload method works.
1. In your GitHub repo, DELETE the old files/folders first.
2. Add file > Upload files > upload ALL files from this zip (index.html, sw.js, manifest.webmanifest, the 3 icon PNGs).
3. Wait ~1 min for Pages to rebuild, then open the link in Safari.
4. If you already added the old version to your Home Screen, delete that icon and re-add it.
Only index.html is truly required; the others add the offline cache and home-screen icon.
